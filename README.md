# Loot, Build and the Gold Scar

**Skyrim** × Fortnite · weapon · idea by the team

Fortnite in Skyrim: the player builds a 3-level tower of wood walls, floors and ramps, kills Fortnite-style soldiers with the gold SCAR held in hand, and opens a Fortnite-style chest that bursts into loot with rarity-colored beams. Look-alike art, close to Fortnite. No storm circle.

> I dropped Skyrim's dragonborn into a Fortnite match: pop a loot chest, grab the gold SCAR, build a wood tower and snipe the Storm from the top.

## Install

Copy the mod's Sigf.esp, Scripts, Meshes, Textures folders into Skyrim Special Edition's Data folder and enable Sigf.esp. Open a Loot Chest, equip the SCAR and use the Build powers to make walls, ramps and floors.
